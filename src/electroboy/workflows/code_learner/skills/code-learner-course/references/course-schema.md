# Course Schema

The canonical course schema named by the invocation is authoritative. Emit one
document record followed by ordered section records. JSONL is the source of
truth; Markdown companions are generated by ElectroBoy.

Use stable IDs and explicit hierarchy. Each section records detail level,
order, parent, knowledge entities, relationships, runtime flows, related
modules and symbols, prerequisites, source references, confidence, and diagram
metadata. Put prose, lists, tables, code, and fenced Mermaid only in `body`.
Use `diagnostic_ids` when a section teaches an uncertainty, exclusion, or
coverage limitation from the supplied knowledge.
Use these canonical field names exactly and emit empty arrays when a section
has no value for a required link collection.

Avoid repeating identical prose at multiple levels. Architecture establishes
the system map, Module explains one boundary and its relationships, and
Function explains one symbol's contract and call flow.
