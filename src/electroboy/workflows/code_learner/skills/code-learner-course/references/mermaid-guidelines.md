# Mermaid Guidelines

Use fenced `mermaid` blocks in section bodies and record diagram metadata with
a stable ID, syntax type, and the knowledge question the diagram answers.

All diagram types supported by the installed ElectroBoy renderer are eligible
for every course mode. Choose the representation that best explains the
evidence; do not encode a closed per-mode allowlist. Multiple diagrams are
appropriate when they explain different structure, runtime, state, data,
deployment, protocol, history, or planning concerns.

Keep node IDs stable and labels concise. Avoid absolute paths. Use syntax that
renders without external resources. Explain each diagram in adjacent prose and
preserve uncertainty through labels, line styles, or notes. If a diagram cannot
be made valid, leave the prose usable and emit a diagnostic or knowledge
request.
