# Layered Navigation

Order sections horizontally within the current Architecture, Module, or
Function course. Populate previous and next section links where the schema
supports them.

Populate explicit deep-dive targets from Architecture components and sequence
participants to modules, from module interfaces and symbols to functions, and
from functions to meaningful callers and callees. Preserve parent and return
links so Back restores the prior horizontal position.

Only link known targets. Missing deeper material remains an addressable target
that ElectroBoy can generate on demand; it must not be represented as an
already available course.
